# 🇨🇦 CarFix Canada Stealth Harvester Node

برنامج استخراج تقارير كارفاکس من كندا مع درع الحماية الشامل ضد الحظر (Anti-Ban & Stealth Engineering).

---

## 🛡️ آليات الحماية المدمجة (Anti-Ban Architecture):
1. **الاتصال بالمتصفح الحقيقي (CDP Remote Debugging):**
   - لا يستخدم المتصفحات الوهمية (Headless) إطلاقاً.
   - يتصل بمتصفح Google Chrome حقيقي يعمل بملف تعريف مستقر (`C:\CarfaxDealerProfile`).
2. **محاكاة السلوك البيومتري البشري:**
   - سرعة كتابة متغيرة تحاكي الإنسان (85ms - 240ms لكل حرف).
   - توقفات طبيعية كل 4-5 أحرف لنقل الشاصي.
   - تحريك الماوس وسكرولينغ قراءة متقطع وتدريجي.
3. **كاشف الخطر المبكر وقاطع الدائرة (Security Tripwire & Circuit Breaker):**
   - يرصد فوراً أي ظهور لتحديات أمنية (Cloudflare, DataDome, reCAPTCHA) أو عودة لصفحة تسجيل الدخول.
   - يوقف المحاولة فوراً دون الضغط على أي زر، ويرسل إشارة إنذار للسيرفر الرئيسي لإيقاف السحب الآلي فوراً حتى يتدخل المشرف يدوياً في كندا.
4. **طابور FIFO وفترة التهدئة الإلزامية:**
   - فاصل زمني لا يقل عن 25 ثانية بين كل عملية سحب وأخرى.
   - حد أقصى 45 تقريراً جديداً يومياً لمنع الاشتباه بالنشاط التجاري المفرط.

## 🚀 طريقة التشغيل على حاسوب كندا:

### الخطوة 1: تشغيل المتصفح الخفي
اضغط مرتين على الملف:
```cmd
start_chrome_stealth.bat
```
سيفتح متصفح Chrome على المنفذ `9222`. قم بتسجيل الدخول إلى حساب كارفاکس التجاري وضع علامة على "تذكرني" (Remember Me).
**اترك نافذة المتصفح مفتوحة دائماً.**

### الخطوة 2: تشغيل عامل كندا (Go Worker)
1. انسخ ملف `.env.example` إلى `.env`:
   ```cmd
   copy .env.example .env
   ```
2. ضع رابط السيرفر الرئيسي ومفتاح الأمان:
   ```env
   SERVER_BASE_URL=https://your-carfix-domain.com
   WORKER_SECRET_KEY=almoq3-canada-secret-2026
   CDP_WS_URL=ws://127.0.0.1:9222
   POLL_INTERVAL_SEC=4
   ```
3. شغل العامل:
   ```cmd
   go run .
   ```
   أو قم بترجمته إلى ملف تنفيذي مستقل:
   ```cmd
   go build -o canada_worker.exe .
   canada_worker.exe
   ```
